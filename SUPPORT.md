# Support

## Getting Help

- Usage questions: open a GitHub Discussion or Issue.
- Bug reports: use the bug report issue template.
- Security concerns: email anthony@making-minds.ai (private disclosure).

## Before Opening an Issue

- Check `README.md` and `docs/start-here.md`.
- Run local validation: `PYTHONPATH=src pytest tests -v`.
- Include wire examples and exact error output.
